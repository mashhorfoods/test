Stage 00 — Global Design System

The system every stage inherits

This is a specimen sheet, not a page design. It documents the tokens, primitives and components that Stage 01 onward must build from. No header, hero, services, pricing or footer is designed here — and no business data appears anywhere on this page.

01

Colour tokens

Charcoal is the foundation, white carries the text, yellow is an accent and an interaction language — never a background. Sections consume semantic tokens only; raw palette values are private.

10

Motion

Durations and easing are tokens, and reduced-motion collapses them at the token level — so a component cannot forget to respect the preference. Content is visible by default; motion never gates it.

Motion tokens
Token Value Use
--duration-fast 180ms Hover, focus, press — immediate feedback
--duration-base 300ms Accordion, tabs, nav indicators
--duration-slow 500ms Scroll reveals, drawer, complex transitions
--ease-out cubic-bezier(.16, 1, .3, 1) Entrances — decelerating, no overshoot
--ease-standard cubic-bezier(.2, .6, .2, 1) State changes and colour transitions

11

RTL / LTR

Layout mirrors automatically because every rule uses logical properties — there is no mirrored stylesheet to maintain. What changes per script is the typeface, letter-spacing (tracking breaks Arabic letter joins), text-transform (Arabic has no case) and line-height.

Naming convention

Class prefixes
Prefix Meaning Example
l- Layout primitive l-container, l-grid
c- Component (BEM: block__element--modifier) c-card__title c-card--featured
t- Typography role t-h2, t-price
u- Utility — single purpose u-text-accent
is- / has- Transient state, set by JavaScript is-open, is-revealed
data-* Behaviour hook — never styled data-accordion, data-reveal
--_name Private custom property, internal to one file --_span, --_bg
