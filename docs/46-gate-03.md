## 5. What could not be verified from here, and why it matters

This environment's egress policy blocks both `zaokalyamamah.online` and
`mashhorfoods.github.io`. Everything above is measured against the artefact on
disk and against a local server. **Nothing has confirmed how the real host
behaves.**

Unverified, and each one is a real failure mode:

| Unknown | If it is wrong |
| --- | --- |
| TLS active and the http→https redirect working | The redirect sends visitors somewhere the server cannot answer |
| `.htaccess` actually uploaded (it is a hidden file) | No compression, no caching, **no CSP, no security headers**, no 404 route, no extensionless URLs — silently |
| Compression negotiated | 487KB shipped instead of ~120KB |
| The rewrite | `/story` and `/pricing` 404 |
| Analytics receiving events | Every KPI stays at zero and nobody notices |

This is why the recommendation is *conditional* rather than a plain go.

## 6. The condition

**Release, then run these four checks immediately. If any fails, upload the
previous zip and tell me what it said.**

```bash
# 1  loads, header shows: Home · Services · Pricing · Story · About
https://zaokalyamamah.online/

# 2  the rewrite is live
https://zaokalyamamah.online/story          https://zaokalyamamah.online/pricing

# 3  our 404, not the host's
https://zaokalyamamah.online/nothing-here

# 4  the headers are actually sent  ← the one that catches a missing .htaccess
curl -sI -H 'Accept-Encoding: gzip' https://zaokalyamamah.online/ \
  | grep -iE 'content-encoding|content-security-policy|x-content-type|referrer'
```

**Within 24 hours of a passing release:**

1. Enable HSTS: set `"hsts": true` in `site.config.json` and run `node build.js`
   — one field, not a hand-edited server file. **Only after check 4 passes.**
2. Confirm one `package_view` in Plausible Realtime.
3. Create the four goals and enable custom properties (`docs/45` §2).
4. Point an uptime check at the homepage.
5. Add the property in Search Console and submit `sitemap.xml`.

## 7. Risks carried into production, knowingly

| Risk | Why it is accepted |
| --- | --- |
| **No moderated user sessions** | Accepted at Gate 02. The site is logically correct; comprehension is untested |
| **One browser engine** | Chromium only in this environment. **Safari on iOS is untested and matters most in this market** |
| **No screen-reader pass** | Landmarks, labels and contrast are necessary, not sufficient |
| **Scope facts drafted, not confirmed** | They are commitments to paying clients. Delivery windows and 50/50 payment are the two most likely to be wrong |
| **Case study without a result** | Chapter 05 has no outcome because none was supplied. It reads honestly and converts less |
| **Arabic unreviewed by a native speaker** | Six pages now. The largest single quality risk in the product |

None of these blocks a release. All of them are cheaper to fix live than to
hold a finished build for.
