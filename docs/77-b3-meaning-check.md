# B3, the half that is not a judgement call

`docs/69` P2 B3. Written 5 September 2026.

**B3 needs a native speaker and this is not one.** Register, tone, whether a
passage reads as translated rather than written, whether `باقة` is the word a
Gulf small-business buyer uses — none of that can be settled here, and
`docs/66` §3's table is untouched by this document.

But `docs/66` §1 said the most valuable thing in that hour is a different
question:

> **Not "does this read well" but "does the Arabic say the same thing as the
> English".** Where it does not, that is a defect rather than a preference, and
> it is the most valuable thing this hour can find.

That is a comparison, not a judgement. **It is done.**

---

## 1. What was compared

The two pages `docs/66` §1 found had **never been reviewed by anyone** — written
after both Arabic passes on 4 September and covered by neither.

| | Bilingual pairs | English | Arabic |
| --- | ---: | ---: | ---: |
| `/terms` | 39 | 909 words | 693 words |
| `/accessibility` | 28 | — | — |

Every pair read side by side, clause by clause. Three mechanical sweeps on top
of the reading, because those are the failures a careful reader misses:

- **Every number in both languages**, compared per pair.
- **Sentence counts** per pair, to catch a clause dropped in translation.
- **Aside and qualifier counts** — em-dashes and semicolons — because a
  qualifier is where an obligation quietly widens.

## 2. The result

**No substantive discrepancy in either page.**

- **Numbers: 0 pairs differ.** The 50/50 payment split, the 14-day quote
  validity, 44×44 pixels, the 1.86:1 watermark contrast, WCAG 2.1 AA, one
  working day — every figure appears identically in both languages.
- **Dropped clauses: none.** Sentence counts match on all 67 pairs.
- **One structural flag, and it is not a defect.** `/accessibility` pair 21
  uses a semicolon in English and a comma-plus-`و` in Arabic — *"they can prove
  that a description exists; they cannot tell you it is the wrong
  description"* against *"تستطيع أن تثبت وجود وصف، ولا تستطيع أن تخبرك أنه
  الوصف الخاطئ"*. Same meaning, different punctuation convention.

The clauses that carry the money and the risk were read most closely, and each
says the same thing in both languages:

| | Both languages say |
| --- | --- |
| **Cancellation** | Stop any time; work completed is payable; the opening 50% is not refundable once work has begun; if we stop, we refund work not delivered and you keep what was handed over |
| **Liability cap** | Limited to what you paid for that piece of work; no lost profit, lost data, or third-party behaviour |
| **Ownership** | Yours on completion and full payment, source files included; ours until then |
| **No result promised** | The work described in the quote, to standard — not a business outcome |
| **Governing law** | Named in the written quote rather than fixed on the page |

## 3. What this unblocks — `docs/65` §2

The lawyer's brief named the governing-language gap as its headline question,
and then said why it could not yet be answered:

> *"it is not merely that no rule exists for a discrepancy — it is that **nobody
> has yet confirmed there is no discrepancy**."*

**Someone has now.** Both versions have been compared in full and they agree.
That changes the question the lawyer is being asked from a two-part one to a
one-part one:

- ~~Do the two versions currently disagree?~~ **No.**
- **Should a governing-language clause be added, and which language should it
  name?** — still entirely theirs, and now the only part of §2 outstanding.

Confirmed while reading: **neither version contains a governing-language
clause.** The absence is symmetrical, which is worth a lawyer knowing.

## 4. What still needs the native speaker, and it is now the whole hour

`docs/66`'s reading order was built around `/terms` first, *because* the
meaning check was the most valuable thing in it. That is spent. **The order
should change**, and `docs/66` is updated:

| Was | Now |
| --- | --- |
| 1. `/terms` — meaning against the English | **Meaning: done. Read it only for register — it is a contract and it should not read like a brochure** |
| 2. homepage — register and tone | **1. homepage** — 2,192 words, the first thing a buyer reads |
| 3. `/pricing` — package names and feature lines | **2. `/pricing`** — where a wrong *term* costs a sale |
| 4. `/story` — "most likely to read as translated" | **3. `/story`** |
| 5. the rest if there is time | **4. `/terms` and `/accessibility`** — register only |

And `docs/66` §3's seven open decisions are untouched by this document —
`باقة`, `الهوية البصرية`, `مونتاج` against `تحرير`, `الوسوم` against
`الهاشتاقات`, Modern Standard as register, whether Arabic marketing here should
run warmer than the English, and whether one Arabic serves both Gulf and Egypt.
**Those are the hour now.**

## 5. What this document is not

It is not a native-speaker review, and B3 does not close because of it.
`docs/69` B3 stays open.

A comparison can tell you the two versions agree. It cannot tell you they are
both good — and the specific risk `docs/47` §5 named for `/story`, that Arabic
written from English reads as translated even when it is accurate, is invisible
to exactly this method. **Two texts can match perfectly and both be stiff.**
